System Workflow

End-to-End 7-Stage Autonomous Pipeline

How the agent transitions from a scheduled background tick in Sri Lanka Standard Time to a published post on LinkedIn.

STAGE 01

4x/Day SLT Trigger

An asyncio background loop checks Sri Lanka Time (UTC+05:30) every 25s and triggers at 08:30, 12:30, 17:30, and 21:00.

STAGE 02

24h RSS News Discovery

Scrapes Google News RSS with when:1d for AI/ML breakthroughs and sorts articles newest-first via published_parsed UNIX timestamps.

STAGE 03

Dual-Table SQLite Guard

Verifies the normalized headline against seen_topics. Even if a draft is later deleted from post_history, that news topic never repeats.

STAGE 04

Dynamic Gemini Router

Queries /v1beta/models live and routes prompts across gemma-3-27b-it and gemini-2.0-flash with a 12s failover timeout.

STAGE 05

Topic-Aware Visual Engine

Extracts domain keywords, fetches fresh imagery via Wallhaven & Openverse REST APIs, and renders a 4x supersampled 1080×1080 Liquid Glass card.

STAGE 06

iOS Lock-Screen Alert

Dispatches an instant UTF-8 JSON push notification via ntfy.sh to my iPhone lock screen without requiring a $99 Apple Developer account.

STAGE 07

Human-in-the-Loop Review & 3-Step Official LinkedIn UGC API Publish

Upon tapping Approve & Publish in the PWA, the backend resolves the author's urn:li:person via /v2/userinfo, uploads the binary 1080×1080 JPEG to /v2/assets?action=registerUpload, and publishes the post to /v2/ugcPosts.

Architectural Decisions

Why This Tech Stack Was Chosen

Every component was selected to maximize reliability, visual quality, and zero-cost 24/7 operation.

Direct Gemini REST API vs. SDKs

Standard SDKs hang in long retry loops when a specific model hits 503 Overloaded. By querying the REST discovery endpoint directly with a 12-second timeout, the agent fails over across multiple models instantaneously.

Pillow Liquid Glass vs. Diffusion APIs

Free AI image generators take minutes, add watermarks, and misspell text. Our programmatic Pillow engine combines live REST photography with 4x supersampled masks and pixel-measured typography in under 2.5 seconds.

FastAPI Asyncio + SQLite Dual-Table

Runs both the web workbench and the 24/7 background scheduler in a single lightweight process using asyncio.to_thread(), backed by zero-config SQLite persistence.

Troubleshooting Case Studies

Real-World Engineering Challenges Solved

Issue Encountered Root Cause Analysis Engineering Resolution
1. Invisible Badge Text on 1080×1080 Card Drawing a low-alpha pill (255,255,255,20) onto an RGBA image overwrote destination alpha; converting to RGB dropped alpha and turned the pill solid white. Engineered a solid off-white pill (245,245,247,255) with near-black typography (15,15,18,255) and an emerald status dot.
2. Cloudflare 403 on Image Search Unofficial web search endpoints blocked Python requests via bot protection, causing fallback to static URLs. Integrated official public REST APIs (Wallhaven v1 & Openverse v1) + a 45-image categorized pool and 25-item LRU cache.
3. Mobile Push Notification Crash Em-dashes (—) and emojis in HTTP headers caused Python latin-1 encoding exceptions. Switched to ntfy.sh's UTF-8 JSON payload API, supporting full Unicode titles and lock-screen action links.
4. Cloud Container Port Collision Gradio 5's Node.js SSR server occupied port 7860 and required a @spaces.GPU startup check. Disabled SSR (GRADIO_SSR_MODE="false"), satisfied the GPU handshake, and mounted FastAPI routes + SHA-256 Auth Middleware directly onto the ASGI router.
